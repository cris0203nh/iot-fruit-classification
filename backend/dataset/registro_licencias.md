# Registro de procedencia y licencias de datos

## AGROP-39

### Datos propios de AgroScan

La base de datos principal utilizada es `backend/data/agroscan.db`.

Las fotografías se recuperan mediante los registros de la tabla `images` y sus relaciones con `evaluations`, `pieces` y `lots`.

Estos registros pertenecen al entorno de trabajo de AgroScan.

### Datos externos

En la revisión realizada no se identificaron fuentes externas de fotografías.

No se atribuye ninguna licencia externa sin verificar la fuente y sus condiciones de uso.

### Incorporación futura de datos externos

Antes de incorporar imágenes externas se deberá registrar:

- Nombre de la fuente.
- Dirección de procedencia.
- Autor o entidad responsable.
- Licencia aplicable.
- Condiciones de atribución.
- Restricciones de uso y redistribución.

### Estado

Pendiente de documentar cualquier fuente externa que se incorpore posteriormente.
