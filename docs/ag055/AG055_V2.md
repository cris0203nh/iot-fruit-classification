# AG-055 V2 — clasificador experimental con región de fruta

V2 implementado como versión separada: `ag055-v2-masked-svc-v1`. Conserva V1, los desarrollos anteriores, las 117 etiquetas originales y SQLite. Los modelos y fotografías permanecen fuera de Git. **No hay validación externa de V2, evidencia Kent ni autorización de cierre de AGROP-67.**

## Cambios y controles

- GrabCut con semilla 5502, núcleo cromático, contorno rellenado y controles de área, forma y múltiples componentes. Los huecos interiores se rellenan para conservar lesiones oscuras y reflejos encerrados por el contorno. Máscara fallida → `no_evaluable`, etiqueta y puntuación nulas; no se fuerza E0/E1/E2. Las máscaras son heurísticas, sin certificación humana. La cobertura parcial queda marcada para revisión.
- Descriptor de 128 componentes calculado exclusivamente en la máscara: histogramas RGB/HSV y gris, gradientes interiores y estadísticos robustos. Matiz HSV solo con saturación ≥32. Se excluye el borde de máscara del cálculo de gradientes. No se conserva el bloque de píxeles globales 24×24 de V1.
- Mediana/IQR calculados únicamente sobre el entrenamiento de cada fold, con piso de escala 0,05 para características normalizadas. No amplifica bins de varianza casi nula. Los controles de segmentación se fijaron mediante inspección de desarrollo; no se seleccionaron con las 40 fotografías anteriores.
- SVC RBF, `class_weight=balanced`, C ∈ {0,5; 3}, gamma `scale`. Selección por F1 macro interno; empate favorece menor C. Después se reajusta únicamente sobre el desarrollo segmentable. Sin calibración de puntuaciones.
- Unión transitiva de grupos conocidos, grupos anteriores, hashes y relaciones perceptuales, antes de separar folds. Duplicados exactos o de píxeles bloquean el entrenamiento: en estas 117 hay cero. Las agrupaciones técnicas **no acreditan identidad física**.
- Artefactos JSON, sin pickle en producción; SHA-256 verificado al cargar. FastAPI incorpora `/vision/quality/v2/status` y `/v2/analyze`, con los permisos existentes. Persiste propuestas idempotentes y reutiliza revisiones/correcciones como eventos nuevos. `proposedGrade=null`, sin confirmaciones automáticas. React presenta V1 y V2 por separado, puntuación no calibrada, versión, rechazo y revisión.

El primer intento de máscara fue demasiado restrictivo; otro conservó trozos de fondo. Se inspeccionaron únicamente imágenes de desarrollo y se reforzó la separación cromática y la solidez mínima 0,94. Los intentos privados anteriores se conservan como desarrollo; la entrega congelada es **V2_05**. Estos ajustes hacen optimistas las métricas internas y no prueban mejora externa.
